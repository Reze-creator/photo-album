# 本地验收与录屏

用项目根目录的启动脚本拉起服务，在浏览器打开 `http://127.0.0.1:8088`。可用两个浏览器配置文件或退出后切换账号，复现主人和访客两种身份。

| 场景 | 操作与期望 |
| --- | --- |
| ★ Nginx 首页 | 打开 `8088`，显示公开广场。页面响应头可见 Nginx |
| ★ 头像注册 | 注册账号 A 并选择一张头像，登录后导航栏展示头像 |
| ★ 创建私有相册 | 相册出现在 A 的「我的相册」，并在公开广场隐藏 |
| ★ 公开相册与照片 | A 创建公开相册并上传 JPG 或 PNG。广场展示相册和创建者信息，访客能打开详情看到图片 |
| ★ 跨用户拒绝 | 记下 A 私有相册的详情地址。登录账号 B 后打开该地址，页面显示权限错误，Network 中详情和照片列表返回 `403` |
| ★ 同源 | Network 中页面、`/api/v1/…` 与 `/uploads/…` 请求的主机和端口均为 `127.0.0.1:8088` |
| 原图保护 | 从 A 的已授权请求中记录私有原图地址，用账号 B 的 Bearer Token 重试应为 `403` |
| 分页 | `go test ./...` 会用每页 1 条验证我的相册及照片列表的翻页内容 |
| 重启 | 保留数据目录，执行停止和启动脚本后，刷新页面仍可使用未到期的 Token |

## 自动化验证

`go test ./...` 默认启动临时 Gin 服务并使用临时 SQLite 数据库。也可以通过 Nginx 运行同一组测试。在项目根目录启动验收实例。

```powershell
.\deploy\start.ps1 -DataDirectory '.\deploy\.runtime\acceptance-data'
```

另开 PowerShell 进入 `backend`，执行下面的命令。测试会创建账号及样例相册，应将目标指向隔离的验收数据目录。

```powershell
$env:ALBUM_TEST_ORIGIN = 'http://127.0.0.1:8088'
go test -count=1 ./...
Remove-Item Env:ALBUM_TEST_ORIGIN
```

3. 展示目录与启动过程，从 Nginx 入口演示上表带星号场景。最后介绍 `/`、`/api/`、`/uploads/` 三类请求的去向。
4. 视频建议不超过 5 分钟，上限为 6 分钟。命名 `姓名_学号_photo-album.mp4`，提交到老师指定的网盘。可将首页、创建与上传、广场、权限错误及 Network 同源的截图放入 `docs/screenshots/`。
